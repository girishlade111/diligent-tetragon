[y=1557 fs=52px] The
[y=1544 fs=52px] brief
[y=1528 fs=17px] Pulse Analytics had three product teams and three versions of every button. Each new feature looked slightly different from the last.
[y=1603 fs=17px] They needed one design system that designers and engineers would both use, not a library that sits in a drawer.
[y=1774 fs=12px] SC 02
[y=1803 fs=52px] What I
[y=1790 fs=52px] did
[y=1793 fs=17px] Printed every component in the product to see the real mess
[y=1859 fs=17px] Defined tokens for colour, type and spacing before drawing any component
[y=1925 fs=17px] Built 140 React components with Storybook docs and visual tests
[y=1991 fs=17px] Ran office hours every Tuesday so teams could ask instead of fork
[y=2058 fs=17px] Redesigned the main dashboard as the first product built only from the system
