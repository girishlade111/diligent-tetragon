[y=1066 fs=32px] The idea
[y=1136 fs=17px] Every team I worked with had two sets of design tokens: the ones in Figma and the ones in code, slowly drifting apart.
[y=1210 fs=17px] I wanted one button that makes them the same again, in either direction, with a readable diff before anything changes.
[y=1338 fs=32px] How it's built
[y=1409 fs=17px] A Figma plugin written in TypeScript. It reads local variables, writes a tokens.json in the W3C format and opens a pull request through the GitHub API.
[y=1467 fs=17px] Reads Figma variables and modes, not styles
[y=1503 fs=17px] Shows a diff before writing anything
[y=1540 fs=17px] Opens a pull request instead of pushing to main
[y=1577 fs=17px] Open source, used by eleven teams I know of

[y=1947 fs=32px] What I learned
[y=2017 fs=17px] Sync tools fail on trust, not on code. People only press the button when they can see exactly what it will change.
[y=2075 fs=17px] Show the diff first, always
[y=2112 fs=17px] Make the safe path the default one
[y=2200 fs=24px] A plugin earns its place the day nobody has to ask which file is right.
