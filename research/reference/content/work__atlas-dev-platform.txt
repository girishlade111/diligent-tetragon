[y=1485 fs=52px] brief
[y=1469 fs=17px] Atlas Cloud's developer docs took six seconds to load and nobody on the team owned the front end. Developers left before they found the page they needed.
[y=1544 fs=17px] I joined as front-end lead for a quarter to rebuild the docs site, set up a design system for it and hand it to the team in good shape.
[y=1715 fs=12px] SC 02
[y=1744 fs=52px] What I
[y=1731 fs=52px] did
[y=1734 fs=17px] Measured where time went: fonts, a heavy search bundle and client-side rendering
[y=1800 fs=17px] Moved the docs to static pages with Next.js and on-demand search
[y=1866 fs=17px] Designed a small set of components for code blocks, callouts and API tables
[y=1932 fs=17px] Paired with two engineers so they could run the system after I left
[y=1999 fs=17px] Set up performance budgets that fail the build when a page gets slow
