[y=1066 fs=32px] The idea
[y=1136 fs=17px] Mesh gradients look great in a design file and terrible as exported PNGs. I wanted gradients that stay sharp at any size and can be painted, not just picked.
[y=1210 fs=17px] Four colour points you can drag, a little grain, and a slow drift so the page never looks frozen.
[y=1309 fs=32px] How it's built
[y=1380 fs=17px] A single fragment shader in WebGL. The colour points are uniforms, the blend is a weighted distance field, and the grain is a cheap hash so it costs nothing to animate.
[y=1438 fs=17px] One full-screen triangle, one shader, no library
[y=1475 fs=17px] Colour points dragged straight on the canvas
[y=1511 fs=17px] Grain added in the shader to hide banding
[y=1548 fs=17px] Falls back to a CSS gradient when WebGL is off

[y=1966 fs=32px] What I learned
[y=2036 fs=17px] Banding is the real enemy of gradients. A tiny amount of noise does more for quality than any extra colour stop.
[y=2094 fs=17px] Add grain before you add colours
[y=2131 fs=17px] Keep a CSS fallback that looks intentional
[y=2219 fs=24px] The best gradient is the one nobody calls a gradient.
