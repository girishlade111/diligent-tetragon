[y=1516 fs=52px] The
[y=1503 fs=52px] brief
[y=1486 fs=17px] Violet Magazine wanted issue 12 to feel collectable. The theme was letters, so the type had to do the work the photos usually do.
[y=1562 fs=17px] I art-directed the issue and a series of posters that came folded inside, each one built from a single letter of the alphabet.
[y=1732 fs=12px] SC 02
[y=1762 fs=52px] What I
[y=1749 fs=52px] did
[y=1751 fs=17px] Picked one typeface family and pushed it from hairline to black
[y=1817 fs=17px] Set a grid that lets every spread break it once, on purpose
[y=1884 fs=17px] Designed six fold-out posters that join into one word on a wall
[y=1950 fs=17px] Worked with the printer on a fluorescent fifth colour for the covers
[y=2016 fs=17px] Built a small web gallery so readers could see all six posters together
