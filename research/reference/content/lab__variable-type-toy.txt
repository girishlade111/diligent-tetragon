[y=1066 fs=32px] The idea
[y=1136 fs=17px] Variable fonts have a weight axis that most sites set once and never touch. I wanted to know what happens when the reader holds the axis in their hand.
[y=1210 fs=17px] One weekend, one screen, one rule: drag anywhere and the letters get heavier the further you pull.
[y=1309 fs=32px] How it's built
[y=1380 fs=17px] A small React component with one animation loop. Pointer distance goes in, an eased weight value comes out, and the text reads it through a CSS variable.
[y=1438 fs=17px] One requestAnimationFrame loop for everything that moves
[y=1475 fs=17px] Weight lives in a CSS variable, not in React state
[y=1511 fs=17px] Works with a mouse, a finger and the arrow keys
[y=1548 fs=17px] Under 4 kB gzipped, no animation library

[y=2014 fs=32px] What I learned
[y=2084 fs=17px] Type reads as alive when it lags the hand by a fraction. Too fast feels like a slider, too slow feels broken.
[y=2113 fs=17px] Tune the easing before the colours
[y=2150 fs=17px] Test on a cheap phone, not on a laptop
[y=2238 fs=24px] Half of the hover states I ship today started as this toy.
