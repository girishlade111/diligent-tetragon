[y=440 fs=19px] Figma is where I think. The browser is where I decide.

[y=1245 fs=32px] Figma is for thinking
[y=1321 fs=17px] I still start every project in Figma. It is the fastest place to try ten layouts and throw nine away. But a layout is a guess about behaviour, and Figma is bad at behaviour.
[y=1441 fs=32px] The browser is for deciding
[y=1517 fs=17px] Loading states, long names, a slow network, a keyboard user — none of that shows up in a frame. So once a flow feels right on paper, I build a rough version in the browser and make the real decisions there.
[y=1605 fs=17px] Build the ugly version first, with real data
[y=1644 fs=17px] Decide spacing and motion where they will live
[y=1683 fs=17px] Bring the finished details back into the design file
[y=1736 fs=31.68px] A frame shows how it looks. A build shows how it feels.
[y=1896 fs=32px] What changed
[y=1972 fs=17px] Reviews got shorter. Instead of arguing over a static screen, the team clicks through the thing and points at what is wrong. Fewer opinions, more fixes.
